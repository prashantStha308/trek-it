# Trek-it
> Search, Book, Customize. **Trek-it.**

Trek-It is a one stop guide booking system for flexible, custom and safety priority travels, focused in Nepal.
Trek-It makes it convenient to find a guide and design a custom itinerary with the guide of your selection.

## Tech Stack
Trek-It uses the MERN stack, a popular tech stack for building scaleable web apps with javascript.
- **M:** MongoDB
- **E:** Express
- **R:** React (Trek-it uses Next.js, a framework built on top of React)
- **N:** Node.js runtime


## Folder Structure
Trek-It will be a mono-repo and will adopt a `feature/function based folder structure` on both frontend and backend.
